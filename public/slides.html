⚠️ The Core Challenge

The $1T Dilemma: Unbounded AI Agents

Autonomous agents can browse, negotiate, and decide. But giving an LLM direct credit card numbers or raw payment API keys is financial Russian roulette.

🌪️

Hallucination & Drift

LLMs misinterpret quantities, order the wrong SKU tiers, or get trapped in runaway execution loops, draining bank balances within minutes.

Risk Level: High Unbounded Loop
🎭

Prompt Injection & Tampering

Adversarial websites and altered seller metadata can trick agents into paying inflated prices or accepting hostile non-refundable terms.

Attack Vector: Web Price Gouging
🔓

All-or-Nothing Access

Payment gateways lack pre-gateway policy enforcement. Once credentials are handed to an agent, there is zero fine-grained spending control.

Legacy Gap Zero Granularity
💡 The Fundamental Question: How do we grant AI agents autonomous purchasing agency without absorbing unlimited financial liability?
🛡️ The Solution

Kavach (कवच): The Trust Rail

A deterministic, cryptographic safety middleware sitting directly between autonomous AI agents and Razorpay's payment infrastructure.

🔏

Cryptographic Passport

HMAC-SHA256 signed catalog manifest. Guarantees prices, inventory, and return policies at signature time. Price tampering breaks validation instantly.

HMAC-SHA256 Tamper-Evident
⚙️

Atomic Mandate Engine

Strict pre-gateway spending bounds: amount ceilings, category allowlists, expiry timestamps, and single-use burn protection.

Hardware-Grade Pre-Gateway Bounds
🛑

Audit Rail & Kill Switch

Append-only audit trail translating machine decisions into plain language, backed by an instant operator revocation kill-switch with 409 conflict protection.

Append-Only Instant Revocation
🎯 Core Principle: Every bound is evaluated before any gateway call. If a rule fails, zero money moves and zero API calls are wasted.
